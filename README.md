# Shatter

Shatter is a browser based gravity well rock shooter. Pilot an inertia driven ship, break armored rocks through their fragments, and use a guided torpedo while the central star bends every ballistic shot.

## Setup

Install dependencies with `npm ci`.

Run the development server with `npm run dev` and open the URL it prints.

Create the static production site with `npm run build`. The complete site is written to `dist/` and can be served from any static file server.

## Controls

- **Arrow keys** or **WASD**: steer and thrust (up thrusts; left and right turn)
- **Space**: fire the gun
- **F**: launch a guided torpedo
- **Enter**: select a menu item
- **Escape** or **P**: pause/resume; Escape also backs out of menus
- **M**: toggle sound
- **Backquote**: toggle the engine debug overlay
